# Emergency Dispatch App Roadmap

This roadmap captures tasks and development phases derived from `emergency_dispatch_prompt.md`.

## Tasks
1. Build modular project skeleton separating HTML, CSS and JS modules.
2. Implement dispatch information form collecting address, time and patient details.
3. Provide service type and condition selection with trauma/non-trauma categories and patient status inputs.
4. Integrate hospital selection with Google Maps and confirmation dialog.
5. Support pricing models for normal and urgent transport with live cost estimates.
6. Show real-time tracking with responder location, ETA and idle-case messaging.
7. Create responder interface with card-based case list and auto-start tracking upon acceptance.
8. Explore advanced features like WebRTC, backend storage and realtime updates.
9. Maintain Uber Eats-like clean, mobile-friendly UI.

## Roadmap
| Phase | Scope | Goal |
|------|-------|------|
| **Phase 1: Architecture (Week 1)** | Establish project folders, shared styles and utilities | Foundation for modular development |
| **Phase 2: User Flow (Weeks 2-3)** | Implement dispatch form, service selection, condition input and hospital choice | Enable end-to-end dispatch request |
| **Phase 3: Pricing & Tracking (Week 4)** | Add cost calculation, map-based tracking and status display | Visualize progress and fees |
| **Phase 4: Responder Interface (Week 5)** | Build case list and acceptance tracking for responders | Support ambulance personnel usage |
| **Phase 5: Advanced Features (Week 6+)** | Integrate WebRTC, persist patient data and enable realtime updates | Enhance immediacy and extensibility |
